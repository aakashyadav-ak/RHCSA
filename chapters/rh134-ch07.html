Archiving Files

Pack many files into one archive with tar, shrink it with gzip, bzip2 or xz, and bring the files back. Includes zip for Windows users.

Why archivetar basicsgzip, bzip2, xzOne file and excludeCompression toolsCommands listQuiz

1Why archive and compress?

Why? Backups, log bundles and file transfers are easier as ONE small file. An archive joins many files into one. Compression makes that file smaller. They are two different jobs.
Full formstar = Tape ARchive. gzip = GNU zip. bzip2 = block-sorting compressor. xz = the .xz format (LZMA2 algorithm).

2tar: -c -x -t -v -f

Why? tar is the standard tool. Learn 5 letters and you can do 90% of the work.
OptionMeaning
-ccreate a new archive
-xextract files
-tlist the content (no extraction)
-vverbose, show file names
-f FILEfile name of the archive. Always right after the letters
-C DIRchange to DIR (extract there)
-pkeep permissions
Only one of c, x, t at a timeAnd -f must be followed by the archive name: tar -cvf backup.tar /etc is right. tar -cfv backup.tar breaks because v becomes the file name.
$ tar -cvf etc-backup.tar /etc/hostname /etc/hosts
tar: Removing leading `/' from member names
/etc/hostname
/etc/hosts
$ tar -tf etc-backup.tar
etc/hostname
etc/hosts
$ mkdir /tmp/restore
$ tar -xvf etc-backup.tar -C /tmp/restore
etc/hostname
etc/hosts
$ ls /tmp/restore/etc
hostname  hosts
Why "Removing leading /"tar removes the first / so that extracting never overwrites real system files by accident. The files come back relative to the current folder (or -C).

3tar with gzip, bzip2, xz

Why? Add one more letter and tar compresses while it archives. Better compression = smaller file but slower.
OptionExtensionSpeedSize
-z gzip.tar.gz or .tgzfastmedium
-j bzip2.tar.bz2slowersmaller
-J xz.tar.xzslowestsmallest
$ tar -czvf logs.tar.gz /var/log/dnf.log /var/log/cron
$ tar -cjvf logs.tar.bz2 /var/log/dnf.log /var/log/cron
$ tar -cJvf logs.tar.xz  /var/log/dnf.log /var/log/cron
$ ls -lh logs.tar.*
-rw-r--r--. 1 student student 41K Nov 20 10:20 logs.tar.bz2
-rw-r--r--. 1 student student 47K Nov 20 10:20 logs.tar.gz
-rw-r--r--. 1 student student 38K Nov 20 10:20 logs.tar.xz
Extract: tar detects the type for youtar -xvf logs.tar.xz works for all three. You do not need z, j or J when extracting (but it is fine to use them).

Reading a name: -czvf = create, gzip, verbose, file.

4Extract one file, exclude files, add to an archive

Why? Real work: restore ONE lost file from a big backup, or skip junk while backing up.

List first, then extract only one file

$ tar -tzf logs.tar.gz
var/log/dnf.log
var/log/cron
$ tar -xzvf logs.tar.gz var/log/cron -C /tmp/restore
var/log/cron
$ ls /tmp/restore/var/log
cron

Type the path exactly as -t shows it (no leading /).

Exclude files

$ tar -czvf home-backup.tar.gz --exclude='*.iso' --exclude='Downloads' /home/student

Add to an existing plain archive

$ tar -rvf etc-backup.tar /etc/fstab
$ tar -tf etc-backup.tar
etc/hostname
etc/hosts
etc/fstab
-r works only on uncompressed .tarYou cannot append to a .tar.gz. Make a new archive instead.

Keep permissions, owners and SELinux labels (system backup)

$ sudo tar --selinux --acls --xattrs -czpf /backup/etc.tar.gz /etc

5Compression tools: gzip, bzip2, xz, zip

Why? Sometimes you compress a single file, for example a big log, without tar. These tools replace the file with a compressed one.
CompressUncompressResult
gzip filegunzip file.gzfile.gz
bzip2 filebunzip2 file.bz2file.bz2
xz fileunxz file.xzfile.xz
$ ls -lh access.log
-rw-r--r--. 1 student student 12M Nov 20 10:30 access.log
$ gzip access.log
$ ls -lh access.log.gz
-rw-r--r--. 1 student student 1.1M Nov 20 10:30 access.log.gz
$ gunzip access.log.gz
$ gzip -k access.log      # -k keeps the original file
  • The original file disappears unless you use -k.
  • zcat file.gz, bzcat, xzcat read a compressed file without extracting.
  • gzip -l file.gz shows compressed and original size.

zip and unzip (also opens on Windows)

$ zip -r project.zip project/
  adding: project/ (stored 0%)
  adding: project/notes.txt (deflated 45%)
$ unzip -l project.zip
$ unzip project.zip -d /tmp/out
zip vs tarzip archives and compresses in one tool and works on Windows. tar keeps Linux permissions and owners, so it is the right tool for Linux backups.
