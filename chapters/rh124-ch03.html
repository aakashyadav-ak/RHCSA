Getting Help from Local Documentation

Learn to solve problems using the help systems already installed on your Linux machine — no internet required.

📖

3.1 What are Man Pages?

A man page (short for manual page) is the built-in instruction manual for a command, file, or function on Linux.

  • Software packages install their own man pages when you install them.
  • You read them from the terminal with the man command.
  • They are stored on disk in subfolders of /usr/share/man.
  • They need no internet. They work offline — the "local help system."
💡 Beginner Analogy
Think of man pages like the user manual that comes in the box with a gadget. Every command ships with its own manual.

Basic Usage

$ man ls # open the manual for the "ls" command $ man passwd # open the manual for "passwd"
📘 History
Man pages come from the old Linux Programmer's Manual. It was so big that it was split into numbered sections, each covering one topic area.
📑

3.2 Manual Sections

The manual is divided into 9 sections:

SectionContent TypePlain English
1User commandsPrograms and shell commands you run (ls, cp, passwd)
2System callsLow-level requests programs make to the kernel
3Library functionsFunctions provided by program libraries (for programmers)
4Special filesDevice files (like those in /dev)
5File formatsHow config files are structured (/etc/passwd)
6Games & screensaversHistorical fun programs
7Conventions, standards, miscProtocols, file systems, general info
8System administrationAdmin/maintenance commands (often need root)
9Linux kernel APIInternal kernel functions
🎯 Which Sections Matter Most for Sysadmins?
  • Section 1 → user commands
  • Section 5 → file formats (config files)
  • Section 8 → admin commands
  • Section 2 → only if you use troubleshooting tools (e.g. tracing system calls)
  • Others → mostly for programmers or advanced admins

Same Name, Different Sections

Some names exist in several sections. The section number is written in parentheses to tell them apart:

ReferenceMeaning
passwd(1)The command to change passwords
passwd(5)The file format of /etc/passwd (where local user accounts are stored)

Choosing a Section

$ man passwd # shows passwd(1) by default $ man 5 passwd # shows passwd(5), the file format $ man 1 su # explicitly the section 1 page for su
📘 Why does man passwd show section 1?
When you don't give a section, man searches the sections in order (1, 2, 3…) and shows the first match.
🧭

3.3 Navigating Man Pages

Man pages open in a pager — a viewer that shows one screen at a time. You can't type commands into it. You use keys to move around.

Navigation Keys

SpaceScroll down one screen
PgDnScroll down one screen
PgUpScroll up one screen
↓Scroll down one line
↑Scroll up one line
dDown half a screen
uUp half a screen
/textSearch forward
nNext match
Shift+nPrevious match
gGo to start
Shift+gGo to end
qQuit to shell
💡 Example: Searching Inside a Page
  1. Type man passwd
  2. Type /expire and press Enter → jumps to the first "expire"
  3. Press n to go to the next one
  4. Press q to quit
⚠️ Regular Expressions in Search
Searches inside man pages use regular expressions (regex). Some characters have special meaning: $ * . ^

Plain words like passwd work normally. But a search like make $$$ may give unexpected results because $ is a metacharacter.
More info: man 7 regex
🧬

3.4 Anatomy of a Man Page

Most man pages use the same headings in the same order. Not every page has every heading.

HeadingWhat It Contains
NAMEName of the command/file plus a one-line description
SYNOPSISQuick summary of the syntax (how to type the command)
DESCRIPTIONBasic explanation of what it does
OPTIONSThe flags/switches and what each does
EXAMPLESReal examples of usage
FILESRelated files and directories
SEE ALSORelated man pages to read next
BUGSKnown problems
AUTHORWho developed it

Reading the SYNOPSIS (Beginner Decoder)

Example from the su page:

su [options] [-] [user [argument...]]
■ [ ] square brackets → optional part
■ ... → can be repeated
■ Words without brackets → required

So su alone is valid. All the parts shown are optional.

💡 Reading Strategy
  1. Read NAME (what is this?)
  2. Skim SYNOPSIS (how do I type it?)
  3. Jump to EXAMPLES if there is one
  4. Use / to search OPTIONS for the flag you need
🔍

3.5 Searching for Man Pages

What if you don't know the command name? Search by keyword.

5.1 man -k — Keyword Search

  • -k searches only the titles and descriptions of man pages.
  • It is equivalent to the apropos command.
  • Output shows the page name + section number + short description.
$ man -k passwd chpasswd (8) - update passwords in batch mode passwd (1) - update user's authentication tokens passwd (5) - password file
💡 Multiple Words
man -k postscript viewer matches pages containing either word ("postscript" or "viewer").

5.2 man -K — Full-Text Search (Capital K)

  • Searches the entire text of all man pages, not just titles.
  • Slower and uses more system resources.
  • It opens the first page with a match. Then:
KeyAction
EnterView this page
Ctrl+DSkip to the next match
Ctrl+CQuit the search

3.5.3 Quick Comparison

⚡ Fast

man -k (lowercase)

Searches titles + descriptions only. Uses the pre-built index database.

🐢 Slow

man -K (UPPERCASE)

Searches full text of every man page. Scans all files on disk.

📘 How does -k work internally?
It reads an index database built by the mandb(8) command.
  • mandb must be run as root
  • The man-db-cache-update service runs it automatically whenever you install a package that has man pages
  • So the index stays up to date without you doing anything

📘 Details Worth Remembering

su login vs non-login shell:

  • su → non-login child shell that keeps your current environment
  • su - → login shell with the target user's full environment
  • -, -l, and --login are all the same option

whereis passwd output:

passwd: /usr/bin/passwd /etc/passwd /usr/share/man/man1/passwd.1.gz /usr/share/man/man5/passwd.5.gz ...
  • /usr/bin/passwd → the program
  • /etc/passwd → the data file
  • /usr/share/man/man1/... and man5/... → the man pages (the man1, man5 folders match the section numbers)

3.7 Lab Walkthrough: Printing and Viewing Docs

Goal: Find, format, view, and "print" documentation using only man pages.
Setup: lab start help-review

Step 1: How Do I Prepare a Man Page for Printing?

$ man man # then look for the "-t" option
  • man -t formats a page for printing.
  • The default output is PostScript (a page-description format used for printing).
  • Example from the manual: man -t bash | lpr -Pps
📘 What is groff?
groff is the text-formatting tool behind man pages. Its default output is PostScript.

Step 2: Create a PostScript File from the passwd Man Page

$ man -t passwd > passwd.ps # save the formatted page to a file $ ls -al # confirm the file exists $ file /home/student/passwd.ps # identify the file type PostScript document text conforming DSC level 3.0 $ less /home/student/passwd.ps # peek inside (press q to quit)
  • > is redirection. It sends output into a file instead of the screen (covered in a later chapter).
  • Inside the file you will see headers like %!PS-Adobe-3.0, which confirms it is PostScript.

Step 3: Find Tools to View/Print PostScript

$ man -k postscript viewer

Found: evince(1), the GNOME document viewer (it handles PostScript and PDF).

Step 4: Use evince

Options learned from man evince:

OptionMeaning
-w / --previewOpen in preview mode (good for quick browsing and printing)
-i NUMBER / --page-index=NUMBEROpen at a specific page
$ evince /home/student/passwd.ps # normal mode $ evince -w /home/student/passwd.ps # preview mode $ evince -i 3 /home/student/passwd.ps # start at page 3

Step 5: Print Only Pages 2 and 3 (Theory Only)

From man lp:

OptionMeaning
-P page-listWhich pages to print, e.g. 1,3-5,16
$ lp passwd.ps -P 2-3
⚠️ Page Numbers
The numbers refer to output pages, not the document's original pages. Options like "number-up" can change the numbering.

Step 6: Browse Local Docs in Firefox

$ firefox /usr/share/doc
  • Open the man-db folder and view the manuals.
  • Open the kexec-tools folder and read kexec-kdump-howto.txt. It explains config options stored in /etc/sysconfig.
💡 Tip
/usr/share/doc holds extra documentation that packages install (separate from man pages).

3.8 Cheat Sheet

# ── Opening Man Pages ── $ man <topic> # open a man page $ man <section> <topic> # open from a specific section # ── Searching ── $ man -k <keyword> # search titles/descriptions (= apropos) $ man -K <keyword> # full-text search (slow) # ── Formatting & Printing ── $ man -t <topic> > f.ps # make a printable PostScript file # ── Finding Files ── $ whereis <command> # find binary, config, and man page locations $ file <filename> # identify a file's type # ── Viewing & Printing ── $ evince -w <file> # preview mode $ evince -i 3 <file> # open at page 3 $ lp <file> -P 2-3 # print pages 2 to 3
💡 Inside a Man Page
/text search · n next · Shift+n previous · g top · Shift+g bottom · q quit

3.9 Key Takeaways

✅ Summary
  • Use man to read man pages, the built-in offline documentation for files, commands, and functions.
  • Reference a page by name + section number, like passwd(5).
  • Sections 1, 5, and 8 matter most for sysadmins.
  • Use /string to search within a page, and q to quit.
  • Use man -k to find pages by keyword when you don't know the command name.
  • The keyword index is built by mandb and updated automatically.
  • Regular expressions work in page searches, so special characters like $ can behave unexpectedly.
